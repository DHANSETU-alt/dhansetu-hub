Rule 48 Tax Invariants

Every tax invoice issued by an Indian registered taxable person must satisfy strict statutory constraints under the CGST Act 2017:

16-Digit Consecutive Numbering Must be unique for each financial year, containing only alphanumeric characters, slashes, or dashes.
Mandatory Place of Supply State code must be explicitly printed with state name to resolve ITC claiming eligibility for the buyer.
HSN/SAC 6-Digit Mandate Turnover >₹5Cr requires 6-digit SAC; turnover <₹5Cr requires 4-digit code on all B2B invoices.
