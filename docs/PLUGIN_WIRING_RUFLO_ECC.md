# Plugin Wiring — Ruflo + ECC (2026-09-16)

Support layer added to Shakthi_Agent: two external Claude Code plugin marketplaces, five plugins total. Documented here so the wiring is traceable later — not auto-generated by Obsidian, since no Obsidian vault exists on this Mac yet (see note at the bottom).

## What was added

### Marketplace: `ruflo` — github.com/ruvnet/ruflo
Formerly "Claude Flow." 67k+ GitHub stars, real npm package, no sudo/system modification on install. Registered in `~/.claude/settings.json` → `extraKnownMarketplaces.ruflo`.

Installed (user scope):
| Plugin | Role |
|---|---|
| `ruflo-core@ruflo` | Core MCP tools, commands, Claude Code orchestration patterns |
| `ruflo-swarm@ruflo` | Agent teams, swarm coordination, worktree isolation |
| `ruflo-rag-memory@ruflo` | RuVector memory — HNSW search, AgentDB, semantic retrieval |
| `ruflo-neural-trader@ruflo` | Neural trading **strategy/backtesting** dev tool — code generation only, does not place live trades |

### Marketplace: `ecc` — github.com/affaan-m/ECC
"Everything Claude Code" — agent harness performance layer (skills, instincts, memory, security, research-first workflows). MIT-licensed, active community adoption. No MCP servers declared; hooks are profile-gated (`minimal` / `standard` / `strict`, default on).

Installed (user scope):
| Plugin | Role |
|---|---|
| `ecc@ecc` | 68 agents, 286+ skills, 94 commands, lifecycle/quality/safety hooks. Has 2 unset `userConfig` options — run `/plugin configure ecc@ecc` to set them. |

## Wiring into Shakthi_OS — status: NOT YET DEFAULT

Both installs succeeded at **user scope**, meaning they're available in any Claude Code session on this Mac — but "by default with Shakthi OS" (auto-loading specifically when working in `/Users/apple/shakthi-os`) needs one more step I couldn't take myself: the harness's auto-mode classifier blocks Claude from editing its own permission/plugin-enablement settings ("self-modification"), even with your go-ahead in chat. This is a deliberate guardrail, not a bug.

**To finish wiring, add this block to `/Users/apple/shakthi-os/.claude/settings.json`** (merge into the existing file, don't overwrite):

```json
"extraKnownMarketplaces": {
  "ruflo": { "source": { "source": "github", "repo": "ruvnet/ruflo" } },
  "ecc": { "source": { "source": "github", "repo": "affaan-m/ECC" } }
},
"enabledPlugins": {
  "ruflo-core@ruflo": true,
  "ruflo-swarm@ruflo": true,
  "ruflo-rag-memory@ruflo": true,
  "ruflo-neural-trader@ruflo": true,
  "ecc@ecc": true
}
```

Once that's saved, every session started inside `shakthi-os` loads all five plugins automatically — that's the actual "by default" behavior.
